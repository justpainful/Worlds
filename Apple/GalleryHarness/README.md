# Isolated gallery harness

This test-only host creates a temporary synthetic database and two PNG files. Its buttons add existing fixture attachments and reorder actual gallery blocks through `GalleryService`, `NativeResourceRepository`, and RustStore. Reopen reads the database again. The missing-file case is rejected before a gallery edit; the host does not import files. No user databases or attachment directories are exposed.

An unknown fixture block with a matching `attrs.bid` is checked for exact content after writes. Unknown blocks without that field are refused by RustStore, because the original `save_blocks` injects it and would otherwise alter the stored content. Physical attachment existence is checked only for this host's new fixture inputs; it is not an attachment authorization or import solution. Existing missing attachments, sandbox scope, secure vaults, non-fixture media, collaboration, and image previews are not implemented here. The UI is not part of the product. The Xcode project and UI test require Apple CI and have not been run locally.
