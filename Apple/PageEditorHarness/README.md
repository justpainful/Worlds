# Isolated page editor harness

This separate XcodeGen project contains only a synthetic fixture. It imports the fixture into a new temporary local database using `NativeSQLiteBackup` and `LocalProjectImportCoordinator.isolatedTestCoordinator`, opens its personal page through `PersonalEditorPersistence`, and hosts the actual TextKit-backed `NativeEditorView`. It has no file picker and cannot select the user's database. The host prevents interactive dismissal while input is unresolved, disables save during marked text, preserves rejected input in the model and asks before discarding unsaved test edits. The original test source bytes are checked after save. This is not a product target or a release artifact.

The UI test edits and selects text, applies bold, saves, closes and reopens, checks the text and reads a persisted bold mark from the reopened document. Its screenshots use only fixture data. It requires a built RustStore XCFramework and a macOS Apple runner with XcodeGen. Neither the project nor test has run on Apple yet. A passing fixture does not prove support for unknown structures, arbitrary marks, rich paste, actual IME composition, crash recovery, shared pages, real security-scoped sources or full Worlds editor parity. The harness leaves cleanup of its unique temporary directory to the OS.
