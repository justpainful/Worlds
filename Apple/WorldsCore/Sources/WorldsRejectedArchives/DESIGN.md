# Rejected edits review

- Subject: Worlds users reviewing a local record of a rejected collaboration update.
- Vernacular: date, reason, channel, byte count, account permission and the original Yjs snapshot.
- Palette: existing Worlds dark canvas #000000, sidebar #111113, surface #1c1c1e, text #f5f5f7 and accent #2e92ff from the app design; use semantic SwiftUI colors so light and dark appearances remain legible.
- Type: SF system text, title 22 pt semantic title2, body 17 pt semantic body, secondary details 13 pt semantic caption; Dynamic Type follows the system.
- Signature: a chronological list of real rejected records followed by the current account's own readable drawing comments and a user-triggered copy action.
- No decorative motion; native navigation and adaptive system surfaces support iPhone, iPad and Mac. Unrecognized and other users' comments are not presented as the current user's text.
