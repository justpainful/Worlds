# Isolated Claude conversation bridge

This experimental adapter joins the existing `ClaudeRunner`, `ConversationCoordinator`, isolated SQLite chat store and `ConversationView`. A committed user message is emitted as accepted before text deltas, and stored messages are reloaded after completion. The service serializes a single run, forwards cancellation and refuses a second send while an assistant result is awaiting a retry. If final persistence fails, the existing coordinator retains the result in memory and the UI exposes Retry saving response. No prompt is sent by the harness until the user enters and sends it. The macOS harness uses the real locally discovered Claude executable, a private temporary synthetic database and local audit file. CI uses an injected fake runner for tests only and never starts the real executable.

The bridge never supplies MCP or tool authorization and does not expose tool input. The underlying runner launches with tools disabled and strict empty MCP config, but this relies on a trusted executable respecting its arguments; a malicious executable can ignore them. The implementation does not authenticate a live Worlds account, authorize page or attachment context, implement approvals, share original conversations, reproduce all original model controls or recover after process termination. The coordinator limits data but does not guarantee full process-tree termination, and the session/result recovery is memory-only. Do not connect the bridge or harness to a real user database or enable it in the product until independent security review, cross-process ownership, process cleanup and Apple validation are complete.

On iPhone and iPad, the existing local process runtime is unavailable. This module does not provide a remote or on-device alternative. Tests cover accepted-before-delta ordering, persisted messages, rejection of an unexpected tool, cancellation and final-save retry using a synthetic runner and temporary SQLite data; they have not run on Apple yet. The separate macOS harness is a build target, not a released app or a demo conversation.
