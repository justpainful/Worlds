# Spreadsheet engine

`WorldsSpreadsheet` reads, edits and evaluates the workbook a spreadsheet resource keeps in `metadata.sheet`, in the shape the desktop writes (`src/spreadsheet/engine.ts`). It is a Swift port of the desktop formula engine, following the Android port (`Android/core/content/.../SpreadsheetEngine.kt`): the same functions, operators, error values (`#DIV/0!`, `#REF!`, `#NAME?`, `#VALUE!`, `#NUM!`, `#N/A`, `#CYCLE!`) and number formatting. `WorldsSpreadsheetTests` checks all 121 cells of the fixture generated by the real desktop engine (`Android/core/content/src/androidTest/assets/spreadsheet-desktop.json`, read in place) and the desktop and Android engine tests.

Everything is a value type. The evaluator runs synchronously and is not shared between threads.

## Model

- `SpreadsheetWorkbook(metadata:)` applies the desktop's `normalizeWorkbook` defaults: 60 rows and 26 columns by default, rows from 10 to 500, columns from 5 to 100, ids `sh_N` and names `Sheet N` when missing, and a valid `activeSheetId`.
- Unknown keys are kept at every level: the workbook, each sheet (`color`, `colWidths`, `rowHeights`, `merges`, `conditionalRules`, `filter` and anything newer) and each cell (`s` with every style key, `note`, anything newer). `metadata(replacingSheetIn:)` changes only the `sheet` key of the resource metadata.
- Emptying a cell without a style or note removes it, as on the desktop; a styled cell keeps its style.
- Adding rows and columns appends at the end, up to the desktop limits. Inserting or deleting in the middle (which shifts formulas) is not ported yet.

## Evaluation

`SpreadsheetEngine.evaluate` follows `evaluateWorkbook`: values are JavaScript `null`, number, string or boolean, text compares by UTF-16 code units, `Number()` parsing and `String(number)` printing follow JavaScript, and display formats follow `toLocaleString("en-US")`, `toFixed` and `toExponential`. It deliberately differs in these places:

- Dates are computed on the UTC calendar, so `YEAR("2026-01-01")` is 2026 in every time zone (the desktop uses the local zone). Text dates accept `YYYY-MM-DD` or `YYYY/MM/DD` with an optional time, like Android.
- An error literal such as `=#N/A` evaluates to that error. The desktop and Android tokenizers loop forever on `#`.
- Very deep formulas and reference chains are bounded so they cannot exhaust the stack: a long chain such as a running total is evaluated from its end first and gives the same result; a single formula nested more than about 80 levels gives `#ERROR!`, and a cycle longer than the bound gives `#CYCLE!` for its cells.
- A range of more than 250,000 cells gives `#REF!` instead of stalling the device.

Cells are evaluated sheet by sheet in sorted key order, the order the stored JSON has after a save. Results only depend on order for cycles caught by `IFERROR`, as on the desktop.

## Not ported

Autofill, reference shifting on insert and delete, `F4` absolute reference cycling, conditional formatting, filters and templates are kept in the data but have no Swift implementation yet. Merged ranges and frozen rows are displayed by `WorldsSpreadsheetViews`; frozen columns are kept but not pinned.
