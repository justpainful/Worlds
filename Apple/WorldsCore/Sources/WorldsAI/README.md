# WorldsAI local runtime scope

On macOS, `ClaudeExecutable` discovers an executable without running it. `ClaudeRunner` starts the selected process without a shell, uses stream-json input/output, disables built-in tools, uses strict MCP configuration, drains stdout and stderr concurrently, limits request and event sizes, serializes runs, and exposes cancellation and a timeout. MCP is absent by default. Supplying an MCP executable also requires an injected host authorizer; the host must verify that this server enforces Worlds account and resource permissions. This module does not provide that server or establish those permissions.

`JSONLineRunAudit` writes only run ID, timestamp and lifecycle state to a caller-selected private file. It does not store prompts, tokens, stderr or model output. This is not equivalent to the existing Worlds `ai_chats`, `ai_messages`, operation history, change aggregation, attachments, session recovery, Keychain token setup, chat references, instructions or tool approval workflow. The host must supply and protect the audit path. CLI system prompts are passed as process arguments, matching the original implementation, and should not contain credentials. Child process descendants are not reliably terminated as a process group, and a descendant holding a pipe open can delay shutdown; this must be addressed before enabling production runs.

Claude Code may not be installed or signed in, and App Sandbox or distribution restrictions may prevent process launch. No real Claude process or user credentials were accessed while implementing this module. On iOS and iPadOS, `ClaudeRunner` returns `unsupportedPlatform`; no compatible remote backend or on-device runtime is implemented. The module is not linked into the app or Package.swift.

Tests use synthetic scripts for stream-json output, cancellation, and MCP denial, and temporary audit files. Script syntax was checked, but the Swift tests and process lifecycle have not been compiled or executed on macOS. The implementation must not be described as verified or functionally equivalent until Apple builds, cancellation under real process trees, authorization, and existing conversation persistence are tested.
