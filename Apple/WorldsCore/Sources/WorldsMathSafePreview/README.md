# Native math preview scope

Original Worlds stores `mathInline` and `mathBlock` source as `attrs.latex`. `src/editor/views/Pages4Views.tsx:13-17` calls KaTeX with display mode, `trust: false`, HTML plus MathML, and an explicit parse-error path. The source editor updates that field; it does not store a rendered image. Preserve the source and unknown attributes when persisting.

This separate candidate view uses SwiftMath 1.7.3 on Apple platforms. Its gate allows ASCII arithmetic, braces, superscripts, subscripts and only `frac`, `sqrt`, `int` and thin-space commands, with a 512-byte and 12-level limit, followed by SwiftMath parser validation. Other source remains visible with an unavailable notice. The original source is always selectable and exposed as an accessibility label. Parser success does not establish visual or semantic equivalence with KaTeX, and accessibility label text is raw LaTeX, not a spoken mathematical expression. SwiftMath's label has not been evaluated with VoiceOver, Dynamic Type, long equations or visual regression. This isolated module must not be wired to the app until its tests, glyph coverage, rendering and accessibility are checked on Apple. Its formula corpus is deliberately small and has not yet been run on Apple.
