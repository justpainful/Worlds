# Experimental native flowchart subset

Original Worlds stores Mermaid source in a ProseMirror `mermaid` node at `attrs.code`. `DiagramSourceDocument` retains that complete node and modifies only the source field. `DiagramSourceEditor` applies to an in-memory binding, not SQLite. Its host must preserve uncommitted drafts and supply authorization, atomic conflict checks, persistence and undo. It refuses to replace a changed baseline. Neither the view nor parser is connected to the product.

`StrictFlowchartParser` accepts only a `graph` or `flowchart` header with LR, TD or TB and fully consumed newline-separated rectangular nodes or simple, unlabelled `-->` chains. It supports the default Worlds example and Unicode node labels. It rejects any unknown directive, punctuation, multiple statements per line, alternate shapes, edge labels, cycles, repeated edges, conflicting labels and edges that skip ranks. Input is capped at 64 KiB, 32 nodes, 64 edges, 8 ranks and 6 nodes per rank to bound preview work. Rejected source remains editable and is never rewritten. A valid preview is a native SwiftUI vector layout, not Mermaid.js layout or complete syntax compatibility. Connection descriptions remain visible and accessible. UI, Dynamic Type, RTL, VoiceOver and visual parity require Apple review.

This subset introduces no third-party dependency and uses the Swift standard library and Apple SwiftUI. Existing isolated math candidate uses [SwiftMath 1.7.3 MIT code](https://github.com/mgriebling/SwiftMath/blob/1.7.3/LICENSE) with separately licensed bundled fonts including [GUST terms](https://github.com/mgriebling/SwiftMath/blob/1.7.3/Sources/SwiftMath/mathFonts.bundle/GUST-FONT-LICENSE.txt) and [STIX terms](https://github.com/mgriebling/SwiftMath/blob/1.7.3/Sources/SwiftMath/mathFonts.bundle/OFL.txt); font-by-font distribution review remains open. Existing MermaidKit candidate has an [MIT license](https://github.com/2389-research/MermaidKit/blob/v2.10.2/LICENSE), but its parser may skip syntax and this subset does not use it. No dependency or product target is changed here.
