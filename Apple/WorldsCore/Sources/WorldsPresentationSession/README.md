# Presentation editing session

This independent value type manages existing slide blocks, stable ordering, bounded undo and redo, and mutations supplied through the existing loss-preserving SlideBlock API. It rejects duplicate IDs, invalid indexes and deleting the last slide. Unknown JSON is preserved because untouched SlideBlock values are retained. There is no persistence, shared editing, permission check, auto-save, conflict resolution, media handling, duplicate-slide ID generation, clipboard, export or presentation UI. It cannot safely save a page that also contains non-slide blocks without a separate policy preserving them. No claim of feature parity or full presentation support is made. This target is not yet part of Package.swift and has not been built or run on Apple platforms.
