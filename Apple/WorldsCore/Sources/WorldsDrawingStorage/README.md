# Drawing record reader

This experimental reader opens only existing SQLite databases in read-only mode, accepts schema versions 10 and 11, and reads a consistent snapshot of a personal drawing's stored scene, seed, operation journal and version scenes. It preserves those JSON strings without decoding and re-encoding them. Workspace pages, shared metadata, deleted pages and any page with a drawing sync binding are rejected. Rejecting all sync bindings is stricter than the original; it avoids reading a replica under the wrong account while account-bound authorization is absent.

The Codable snapshot is only an internal record representation. It does not include original attachments, pinned dependency ownership, experiment branches, library publication data or a full database backup. It is not a `WORLDSDRAW1` portable project, a visual export, or a restorable archive. The reader cannot create, save, restore or alter a drawing. Initial empty drawings with no stored document are explicitly unavailable rather than synthesized.

The original `src-tauri/src/drawing.rs` save path checks account and device identity, validated operations and the full scene, base revision, attachment permissions, pixel guards and version restore receipts. It writes scene and journal, queues collaboration, updates search and links, records history, and emits change notifications in one transaction. It imports Tauri AppState, account permissions, drawing sync, attachment/store services, history and annotations. `src/drawing/package.ts` and `src-tauri/src/drawing_package.rs` additionally handle package versions, originals, digests, histories, pinned snapshots and experiments. Extracting that path requires separating Tauri command wrappers from the store core and supplying real identity, authorization, attachment storage and synchronization dependencies; replacing these with permissive stubs would be unsafe. Until that extraction is complete, writes and project export remain disabled.

Tests use a temporary synthetic SQLite database and check opaque round-trip and rejection of shared/bound pages. They have not run on Apple SDKs. The module is not connected to the app. Snapshot output should be treated as sensitive user data and not presented as a complete backup.
