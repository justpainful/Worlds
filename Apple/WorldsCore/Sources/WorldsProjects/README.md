# WorldsProjects scope

This independent module preserves the full page metadata tree and implements the `metadata.project` fields used by ProjectView: status, start and due dates, description, and linked resource IDs. Missing fields use the original view defaults. Unknown metadata and unknown resource kinds remain intact. Child resources are filtered and ordered like `childrenOf` in the original: deleted, template and archived children are excluded. Linked items retain their parent and may be archived, but deleted items are omitted. Linking rejects self, duplicates, visible children, deleted resources and templates.

`ProjectService` depends on an injected repository with an atomic compare-and-swap contract. The repository and caller must enforce account/workspace permissions and provide an already authorized resource list. Revision values must distinguish every relevant mutation; the original millisecond updatedAt field alone may collide and is not a sufficient guarantee by itself. This module does not supply a production repository, create real pages or resources, update the FTS index, record history, issue sync events, validate external attachment ownership, or coordinate shared workspaces. It is not attached to the app or Package.swift.

Tests use an isolated copy of the synthetic schema-v11 fixture and a test-only SQLite repository. That fixture repository increments its own revision for deterministic conflict testing and is not a port of the original store. Date validation is deliberately strict ISO Gregorian; existing malformed dates remain untouched unless explicitly edited. Tests have not been compiled or run on Apple.
