# Screen drawing on macOS

This isolated module is included in SwiftPM but is not connected to the application. On macOS 14 and later, `ScreenCaptureSource` checks the existing screen-recording permission without requesting it, looks up an explicitly selected display, excludes the current process's windows, and asks ScreenCaptureKit for one still image. It does not start a recording or retain a capture stream. `ScreenDrawingSession` opens a native borderless window on that display with a still image, pen, highlighter, whole-stroke eraser, laser, color, width, lifetime, undo, clear and close controls. Escape also closes the overlay. A screen topology change closes the window if its selected display disappears or its frame changes. Closing clears the document and image references, invalidates the timer, and destroys the window. Closing while a capture is pending prevents that capture from showing a window later.

The image freezes visually. The application or video behind it is not paused. Drawing stays in memory and is not saved, exported, shared or sent elsewhere. The overlay uses an independent stroke model and an approximate AppKit renderer; it is not the full Worlds drawing engine. The eraser removes a whole touched stroke rather than erasing pixels. Laser, pressure and highlighter visuals have not been compared to the original. The toolbar currently has English labels, no Dynamic Type or RTL review, and needs adaptive layout and accessible control review. Reduce Motion, color profile handling, backing-scale changes, display rotation, high-DPI alignment and full-screen Spaces behavior require real macOS verification.

No screen capture, recording permission request, or real user screenshot was performed during development or tests. The XCTest suite uses an injected synthetic image and tests memory-only drawing behavior. Tests have not been built or run on macOS. Before enabling this feature, wire it only to an explicit user action after security review, select the intended display, test permission-denied and cancellation states, verify all monitor geometries and scale factors, visually review the overlay, and make its lifetime and the discard of annotations clear to users. Secure or protected content may be omitted by macOS.

This mechanism is macOS-only. iOS and iPadOS do not provide an equivalent general-purpose window that can capture and draw over arbitrary other apps. ReplayKit and system broadcast mechanisms are not drop-in replacements and require separate user interaction and platform review.

Official references: https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager/captureimage(contentfilter:configuration:completionhandler:) and https://developer.apple.com/documentation/screencapturekit/sccontentfilter/init(display:excludingapplications:exceptingwindows:).
