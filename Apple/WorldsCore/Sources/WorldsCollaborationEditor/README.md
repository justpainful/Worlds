# Experimental collaborative insertion adapter

This module translates a UTF-16 insertion in a `RichTextDocument` projection into a checked `CollaborationSession.insertPlain` call. It accepts only one unformatted top-level paragraph containing a single ordinary text node with a unique block ID, a zero-length selection, a valid Unicode boundary, and no marked-text composition. It does not mutate the document or show an optimistic result. The session must establish live edit permission and persist the CRDT update plus outbox before applying it.

The session exposes a conservative paragraph-only JSON projection of its live Yjs document after authenticated initial synchronization and durable remote persistence. It includes bold, italic, underline and strike runs when mark values are empty objects or the legacy boolean fixture; other marks, nonempty mark attributes, and unsupported nodes or attributes reject the projection. The planner compares the displayed tree and full CRDT state before insertion, deletion or formatting. The checked store independently verifies the full base and permissions before persisting both the change and outbox atomically.

This is not a complete native editor binding: it does not push remote edits into the view, map relative cursor positions, edit rich text by insertion or deletion, handle nested content, resolve conflicts, or coordinate real IMEs. Deletion is limited to part of a single unformatted text node and cannot empty the paragraph. Formatting is limited to the four basic marks within one paragraph; unknown marks are rejected rather than discarded. It must not be connected to product UI. Rust tests use Yjs fixtures; Swift and Worker coverage of the new path await Apple CI.
