# WorldsOfficePreview scope and dependency review

This independent module provides bounded, read-only DOCX text extraction and XLSX cached-cell previews. It uses ZIPFoundation 0.9.20 as a separate Swift package dependency and depends on WorldsMedia for its authorized attachment file handle. No ZIP content is extracted to disk. All archive entries are checked for path traversal, directory traversal, drive paths, symlinks, duplicate case-normalized names, entry count, declared uncompressed sizes, aggregate sizes and extreme compression ratios. Selected entries are extracted through ZIPFoundation's streaming consumer with separate actual-output counters and CRC checks. Malformed or unsupported files fail rather than falling back to unchecked extraction.

XML is accepted only as UTF-8 and is rejected before parsing if it contains a DTD or entity declaration. External entity resolution is disabled, and parser depth, element count and attributes are bounded. Workbook relationships are restricted to internal worksheet paths. Cell formulas are displayed as data and are never evaluated. The parser does not read external links, macros or images.

DOCX output is plain paragraph text. XLSX output contains worksheet names, row numbers, cell references, cached values and formula strings. Formatting, page layout, charts, images, tracked changes, formula evaluation, styles, date formatting, XLS, ODS, editing, saving and export are not implemented. Original bytes remain untouched. The parser is a limited preview, not full OOXML compatibility.

ZIPFoundation review on 2026-11-07: official GitHub repository `weichsel/ZIPFoundation`, MIT license, release 0.9.20 published 2025-09-24, repository not archived. GitHub's public advisories endpoint returned no advisories at review time; this does not prove the dependency free of vulnerabilities. The pinned release's Archive(data:accessMode:) and streaming extract consumer, size, type and checksum APIs were inspected. Version 0.9.20 is pinned in SwiftPM; Xcode/Swift and deployment compatibility, transitive behavior and performance require Apple CI verification.

Synthetic tests cover actual DOCX/XLSX archives, Arabic text, shared strings, formulas, DTD, traversal, duplicate names, symlinks, oversized entries and forged declared sizes. The Swift tests have not been compiled or run on Apple, and this module is not linked to the application.
