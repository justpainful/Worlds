صفحات HTML

صفحة HTML نوع من الصفحات محتواه مستند HTML واحد. يعرضه Worlds في بيئة معزولة، بأسلوب يشبه بقية صفحاتك. هي للأشياء التي لا تناسبها الكتل: حاسبة، أو متابعة لها منطقها الخاص، أو تقرير من صفحة واحدة بتصميم مرتب، أو شرح تفاعلي صغير.

صفحات HTML ليست في الإصدار الحالي من Worlds. هذه الصفحة تشرحها كما ستصل في إصدار قادم.

إنشاء صفحة HTML

  1. أنشئ الصفحة

    في تطبيق Windows اختر صفحة HTML جديدة من قائمة الإنشاء (بعد الرسم) أو من لوحة الأوامر. وصفها: «صفحة مصممة بلغة HTML: أداة أو متابعة أو تقرير». تبدأ الصفحة بمحتوى أولي بلغة الواجهة.

  2. اكتب أو اطلب من Claude

    بدّل بين صفحة والمصدر. في وضع المصدر يظهر المحرر بجانب الصفحة وهي تعمل. أو اطلب من Claude أن يبني الصفحة لك.

  3. الحفظ تلقائي

    يُحفظ المصدر بعد لحظة من آخر ضغطة مفتاح. إن كسر المصدر قاعدة ترى لم يُحفظ مع سبب الخطأ، وتبقى الصفحة على آخر نسخة سليمة.

القواعد

هذه القواعد تحمي جهازك وصفحاتك. إذا كُسرت قاعدة منها يُرفض الحفظ مع السبب:

  1. مستند واحد مكتفٍ بذاته، حتى 1 MB. مستند كامل، أو محتوى <body> فقط ويكمله Worlds.
  2. لا شيء من الإنترنت. لا <script src>، ولا ملفات أنماط أو @import من عنوان، ولا صور أو فيديو أو صوت من رابط. الصور تكون SVG داخل الصفحة أو عناوين data:. البيئة المعزولة تمنع الشبكة تمامًا.
  3. لا تضمين ولا تحويل. لا <iframe> ولا <object> ولا <embed> ولا <base> ولا <meta http-equiv> ولا <form action>.
  4. السكربتات داخل الصفحة فقط. تعمل بلا شبكة، وبلا ملفات تعريف ارتباط أو تخزين، وبلا وصول إلى Worlds أو إلى صفحات أخرى.

وهناك قواعد تصميم تظهر تنبيهات، لكن الصفحة تُحفظ معها:

  • الألوان من متغيرات Worlds مثل --w-text و--w-surface و--w-accent، لا ألوان ثابتة كثيرة.
  • الصفحة تعمل من عرض 360 px إلى عرض الصفحة كاملًا، دون 100vh ودون position: fixed.
  • النص العربي باتجاه من اليمين إلى اليسار: lang="ar" dir="rtl". يضيفه Worlds إن كان التطبيق بالعربية ولم تحدده الصفحة.
  • تصميم هادئ ومحتوى حقيقي، دون نصوص تجريبية أو أرقام مختلقة.

عناصر HTML العادية (العناوين والفقرات والقوائم والجداول والأزرار وحقول الإدخال) لها أسلوب Worlds جاهزًا. وهناك فئات جاهزة مثل .w-card للبطاقة، و.w-stat لرقم مع عنوانه، و.w-bar لشريط تقدم، و.w-grid لأعمدة تلتف.

حفظ البيانات: worlds.save

الصفحة لا تستطيع استخدام تخزين المتصفح. لتتذكر حاسبة أو متابعة ما أدخلته، تستخدم كائن worlds:

worlds.state
آخر قيمة JSON حفظتها الصفحة، أو null
worlds.save(value)
يحفظ قيمة JSON مع الصفحة، حتى 256 KB. إن كانت أكبر يرمي خطأ.
worlds.lang
"ar" أو "en"، لغة التطبيق
<button id="add">+1</button> <b id="n"></b>
<script>
  let count = (worlds.state && worlds.state.count) || 0;
  const show = () => { document.getElementById("n").textContent = count; };
  document.getElementById("add").onclick = () => { count++; worlds.save({ count }); show(); };
  show();
</script>

من لا يملك صلاحية تعديل الصفحة يستطيع استدعاء worlds.save، لكن لا يُحفظ له شيء.

الروابط: https:// وmailto: تفتح في المتصفح بعد أن تضغطها. وworlds://page/ متبوعًا بمعرّف صفحة يفتح صفحة أخرى في Worlds.

على كل منصة

المنصةما تراه
Windowsالصفحة تعمل داخل Worlds، مع وضع المصدر لتعديلها. ارتفاعها يتبع محتواها.
Androidالصفحة تملأ الشاشة وتعمل بلا إنترنت، ويعمل worlds.save. المصدر للقراءة فقط: «تعمل هنا بلا إنترنت. عدّل مصدرها من Worlds على الحاسوب.»
iPhone وiPad وMacالصفحة تملأ الشاشة وتعمل بلا إنترنت، والمصدر للقراءة فقط. يعمل worlds.save عندما تكون الصفحة في مساحة عمل أو نسخة محلية يمكن الكتابة فيها، وإلا ترى «للقراءة فقط».

على الجوال تفتح الروابط فقط بعد أن تضغطها، وللصفحة هامش 16 px من حواف الشاشة.

كيف يكتبها Claude

اطلب من Claude في المحادثة صفحة HTML، مثل «حاسبة لمعدلي الدراسي» أو «متابعة لمصاريف الشهر». لديه ثلاث أدوات:

  • html_pages_rules: يقرأ القواعد أعلاه قبل أن يكتب.
  • html_pages_read: يقرأ مصدر الصفحة وبياناتها المحفوظة والأخطاء والتنبيهات.
  • html_pages_write: يكتب المصدر. يُرفض إن كسر قاعدة، ولا يمس البيانات المحفوظة.

ويستطيع إنشاء صفحة HTML جديدة مباشرة. قبل كل كتابة يحفظ Worlds نسخة من الصفحة، فتتراجع عن أي تغيير من السجل. الأدوات نفسها متاحة لأي برنامج يتصل عبر خادم MCP.

النص الظاهر في صفحة HTML يدخل في البحث مثل أي صفحة أخرى.
