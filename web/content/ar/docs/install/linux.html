تثبيت Worlds على Linux

لـ Linux ملفان بنفس التطبيق: AppImage يعمل على أغلب التوزيعات بدون تثبيت، وحزمة deb تثبّته في Ubuntu وDebian وما بُني عليهما. اختر واحدًا.

قبل أن تبدأ

AppImage
Worlds-1.1.0-Linux-x86_64.AppImage (95.4 MB)
deb
Worlds-1.1.0-Linux-amd64.deb (21.2 MB)
النظام
Linux بمعالج 64 بت (x86_64)، مع WebKitGTK 4.1. موجود في Ubuntu 22.04 وما بعده، وDebian 12، وFedora 39.
مكان صفحاتك
~/.local/share/Worlds، وفيه الملف worlds.db ومجلد المرفقات

بملف AppImage

  1. حمّل الملف

    من صفحة آخر إصدار على GitHub، في قسم Assets اضغط Worlds-1.1.0-Linux-x86_64.AppImage.

  2. اجعله قابلًا للتشغيل

    في مدير الملفات: الزر الأيمن على الملف، ثم الخصائص، ثم الأذونات، وفعّل «السماح بتشغيله كبرنامج». أو من Terminal:

    chmod +x ~/Downloads/Worlds-1.1.0-Linux-x86_64.AppImage

  3. شغّله

    اضغطه مرتين، أو شغّله من Terminal بمساره. إذا ظهر خطأ عن FUSE في Ubuntu 22.04 وما بعده، ثبّت المكتبة التي يحتاجها AppImage:

    sudo apt install libfuse2

    في Ubuntu 24.04 اسم الحزمة libfuse2t64.

بحزمة deb

  1. حمّل الحزمة

    من صفحة الإصدار نفسها، اضغط Worlds-1.1.0-Linux-amd64.deb.

  2. ثبّتها

    افتح Terminal في مجلد التنزيلات وشغّل:

    sudo apt install ./Worlds-1.1.0-Linux-amd64.deb

    يثبّت apt معها المكتبات الناقصة. بعدها يظهر Worlds في قائمة التطبيقات.

التأكد من الملف

ضع الملف وSHA256SUMS.txt في مجلد واحد وشغّل sha256sum -c SHA256SUMS.txt --ignore-missing. يكتب الأمر OK بجانب الملف السليم. التفاصيل في صفحة التثبيت.

الإزالة

AppImage: احذف الملف. deb: sudo apt remove worlds. صفحاتك تبقى في ~/.local/share/Worlds حتى تحذف المجلد بنفسك.
