خادم MCP في Worlds

Worlds يأتي بخادم MCP يتيح لـ Claude Code أو أي برنامج آخر يدعم MCP أن يقرأ صفحاتك ويعدّلها على جهازك، بالأدوات الآمنة نفسها التي يستخدمها المساعد داخل التطبيق. كل كتابة تُحفظ قبلها نسخة ويمكن التراجع عنها.

ما هو

MCP طريقة معيارية تتصل بها برامج الذكاء الاصطناعي بالأدوات. خادم Worlds هو تطبيق Worlds نفسه يعمل بوضع خاص: worlds.exe --mcp. يتحدث مع البرنامج عبر الإدخال والإخراج القياسيين على جهازك، ويفتح قاعدة بيانات Worlds المحلية مباشرة. لا يمر شيء عبر الإنترنت ولا عبر خوادم Worlds.

الخادم متاح في تطبيق Windows.

الربط مع Claude Code

من داخل Worlds (الأسهل)

  1. افتح الإعدادات، Claude

    في مجموعة Claude Code تجد صف «استخدام Worlds من جلسات Claude Code».

  2. اضغط تسجيل

    يضيف Worlds خادم أدواته إلى إعدادات مستخدم Claude Code. ترى «أدوات Worlds مسجّلة في Claude Code». يكون الزر معطلًا إن لم يجد Worlds تطبيق Claude Code على الجهاز.

  3. ابدأ جلسة Claude Code جديدة

    الآن «يمكن لجلسات Claude Code قراءة الصفحات وتعديلها عبر الأدوات الآمنة نفسها». وفي شاشة التكاملات يظهر «متاح أيضًا في جلسات Claude Code».

إن نقلت Worlds إلى مكان آخر أو أعدت تثبيته، اضغط إعادة التسجيل.

بالأمر يدويًا

هذا هو الأمر الذي ينفذه زر التسجيل. المسار هو مكان التثبيت المعتاد لـ Worlds على Windows. إن ثبّته في مكان آخر فضع مسار worlds.exe عندك:

claude mcp add --scope user worlds -- "%LOCALAPPDATA%\Worlds\worlds.exe" --mcp --actor ai

--scope user يجعل الأدوات متاحة في كل مشاريعك. و--actor ai يسجّل التغييرات باسم الذكاء الاصطناعي في سجل Worlds، فتعرف من غيّر ماذا.

برامج MCP أخرى

أي برنامج يشغّل خادم MCP محليًا عبر الإدخال والإخراج القياسيين يحتاج إلى أمر ووسائط:

الأمر
%LOCALAPPDATA%\Worlds\worlds.exe (أو مسار التثبيت عندك)
الوسائط
--mcp --actor ai
النوع
stdio

بالصيغة التي تستخدمها أغلب البرامج:

{
  "mcpServers": {
    "worlds": {
      "type": "stdio",
      "command": "C:\\Users\\YOU\\AppData\\Local\\Worlds\\worlds.exe",
      "args": ["--mcp", "--actor", "ai"]
    }
  }
}

Codex داخل Worlds (من الإعدادات، المزوّدون) يحصل على أدوات Worlds تلقائيًا. لا يوجد في Worlds زر يسجّل الخادم في Codex الذي تستخدمه خارج التطبيق، فأضفه بالأمر والوسائط أعلاه.

أي مساحة عمل يستخدم

يفتح الخادم قاعدة بيانات Worlds على جهازك: %APPDATA%\Worlds\worlds.db. وإن كان متغير البيئة WORLDS_DATA_DIR مضبوطًا فيستخدم المجلد الذي فيه. تطبيق Worlds يرى التغييرات التي يجريها الخادم ويحدّث الصفحات المفتوحة.

وفي إصدار قادم مجموعتان أخريان:

  • صفحات HTML: html_pages_rules وhtml_pages_read وhtml_pages_write. اقرأ صفحات HTML.
  • التخطيط والدراسة: planning_list وplanning_create وplanning_update لعناصر حزمة الدراسة: المواد والحصص والاختبارات والواجبات وما يُحضر والمهام والدروس والأهداف. planning_create ينشئ حتى 200 عنصر في طلب واحد، مثل مادة مع حصصها الأسبوعية.

الأمان والتراجع

  • كل كتابة تُسجَّل مع من أجراها، وتُجمع تغييرات الجلسة الواحدة معًا.
  • قبل أول تغيير في صفحة يحفظ Worlds نسخة منها.
  • history_undo يعيد كل ما تغيّر في عملية واحدة، وversions_restore يستعيد نسخة ويحفظ الحالة الحالية نسخةً أيضًا.
  • من التطبيق: افتح الصفحة، ثم لوحة السجل، واضغط تراجع بجانب مجموعة التغييرات. اقرأ السجل والنسخ.
  • الأدوات تعمل على صفحات Worlds فقط. لا تعطي البرنامج وصولًا إلى ملفات جهازك ولا سطر أوامر.

الإرسال إلى Discord ينتظر موافقتك

discord_send وdiscord_edit وautomations_run لا ترسل شيئًا. تضع الطلب في قائمة بانتظار الموافقة في شاشة النشاط في Worlds، ويرد الخادم بأن لا شيء أُرسل وأن الطلب ينتظر موافقتك. والأتمتة التي ينشئها برنامج عبر MCP تُحفظ دائمًا مع انتظار الموافقة قبل كل إرسال. لتوافق يجب أن يكون تطبيق Worlds مفتوحًا. اقرأ قائمة الموافقة.
