القصة

بدأت من تشتت الأدوات

كان صاحب المشروع يتنقل بين أدوات كثيرة ليرتب ملاحظاته، فبنى Campus للدراسة: يسجل الملاحظات بالجوال ثم يوصله بالكمبيوتر لتنتقل محليًا. لكن تلك النسخة بقيت محصورة بالدراسة، وتنقصها وظائف احتاجها خارجها، فأعاد بناءها من الأساس باسم Worlds.

  1. 01ملاحظات على الجوالنسخة Campus بدأت من احتياج واضح للدراسة ونقل الملاحظات محليًا.
  2. 02احتياجات تتوسعصار العمل يحتاج إلى ملفات ورسم وشرائح ومشاريع مترابطة.
  3. 03إعادة بناء كاملةتغيّرت الهيكلة والواجهة واتسع نطاق الفكرة حتى أصبحت Worlds.

Claude داخل Worlds

يقرأ صفحاتك ويعدّلها بأدوات Worlds، وتتراجع عن أي تعديل

في ويندوز تختار Claude Code أو Codex، أو مفتاح API من مزود تختاره، أو نموذجًا يعمل على جهازك بدون إنترنت مثل Ollama. في أندرويد يعدّل الصفحات ويضيف المهام مع تراجع بخطوة واحدة، وفي آيفون وآيباد وماك محادثة حقيقية بالمزودين أنفسهم. الطلبات تذهب من جهازك إلى المزود الذي اخترته مباشرة.

كيف تربط Claude ومزودي الذكاء الآخرينربط Claude Code بمساحتك عبر MCP
