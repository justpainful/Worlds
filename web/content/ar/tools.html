الأدوات حول Worlds

Worlds مساحة عمل على جهازك: صفحات ومستندات وجداول ورسومات وعروض. وحولها أدوات تجعل Claude يعمل معك داخلها، وتربطها ببرامج أخرى، وترسل صفحاتك في مواعيدها. هذه نظرة سريعة عليها.

Claude داخل Worlds

مساعد يقرأ صفحاتك ويكتب فيها ويرتبها، وكل تغيير يجريه يمكن التراجع عنه بضغطة. تشغّله بحساب Claude Code أو Codex، أو بمفتاح API من Anthropic أو OpenAI أو Gemini أو Groq أو DeepSeek أو Mistral أو xAI أو OpenRouter، أو بنموذج على جهازك عبر Ollama أو LM Studio. يعدّل الصفحات في Windows وAndroid، ويحادثك فقط على iPhone وiPad وMac حاليًا.

Claude والمزوّدون الآخرون

خادم MCP

يتيح لـ Claude Code أو أي برنامج يدعم MCP أن يستخدم أدوات Worlds على جهازك: الصفحات والكتل والجداول والرسومات والعروض والأتمتة والقوالب والسجل. تسجّله بضغطة من الإعدادات أو بأمر واحد، وكل كتابة تُحفظ قبلها نسخة.

خادم MCP في Worlds

صفحات HTML

صفحة محتواها مستند HTML واحد يعمل في بيئة معزولة بلا إنترنت: حاسبة، أو متابعة، أو تقرير مصمم. تحفظ بياناتها بـ worlds.save، ويكتبها Claude لك. قادمة في إصدار قريب.

جسر Discord

أرسل صفحة إلى قناة أو سلسلة أو رسالة خاصة في Discord، مع معاينة قبل الإرسال. في Windows عبر بوتك الخاص، وفي Android عبر رابط ويب هوك. ما يجهّزه Claude أو الأتمتة ينتظر موافقتك.

جسر Discord

الأتمتة

أرسل صفحة في موعد: مرة واحدة، أو يوميًا، أو أسبوعيًا، أو شهريًا. يمكن أن يجهّزها Claude قبل الإرسال، أو أن تلخّصها بالذكاء الاصطناعي وتعرضها إشعارًا على Android.
