Troubleshooting

Each problem here has a title like what you see on screen, then its cause and the fix step by step.

Windows: “Windows protected your PC” with no way to continue

Cause: the setup file is not signed with a certificate, so Microsoft Defender SmartScreen shows a warning before running it.

  1. Click the More info link under the text. The button does not appear before that.
  2. Make sure the app name is Worlds-0.3.2-Windows-x64-setup.exe, then click Run anyway.

The drawings are in the Windows install steps. If Run anyway never appears, your PC follows a policy that blocks unknown apps, which is common on work and school PCs. Ask whoever manages the PC, or use Worlds in the browser.

Windows: the browser blocked or deleted the file

Cause: Edge and Chrome warn about new programs that few people have downloaded.

  • Edge: open Downloads (Ctrl + J), click the three dots next to the file, then Keep, then Show more, then Keep anyway.
  • Chrome: open Downloads (Ctrl + J) and choose Keep next to the file.

Download the file only from the releases page on GitHub, and check its fingerprint as shown in the install overview.

Windows: I closed Worlds but it is still running, or setup says it is running

Cause: the close button hides Worlds in the notification area, so scheduled automations keep running.

  1. Look for the Worlds icon next to the clock. If you cannot see it, click the small arrow that shows hidden icons.
  2. Right click it and choose Quit.
  3. Run the setup file again.

If you want Worlds to quit when you close the window, turn off Keep running in the tray in Settings. Note that automations do not run while it is closed.

Windows: Worlds does not open, or a message mentions WebView2

Cause: Worlds shows its interface through Microsoft Edge WebView2. If that component is missing or broken, the window does not appear.

  1. Run the Worlds setup file again. It contains WebView2 and installs it if it is missing.
  2. Open Settings, then Apps, then Installed apps, and find Microsoft Edge WebView2 Runtime. If it is there with a Modify option, choose it to repair it.
  3. If that does not fix it, install the WebView2 Runtime from Microsoft's official page (choose Evergreen), then open Worlds.

On work PCs, policies may block installing WebView2. Ask whoever manages the PC.

Mac: “Worlds” Not Opened, or “Worlds” cannot be opened

Cause: the app is not signed or notarized by Apple, so Gatekeeper blocks it the first time.

  • macOS 15 and later: click Done, then open System Settings, then Privacy & Security, scroll to Security, click Open Anyway, and confirm with your password.
  • macOS 14: right click the app in Applications, choose Open, then Open in the alert.

If Open Anyway does not appear, try opening the app again, then go back to Privacy & Security within an hour. The drawings are in the Mac install steps.

Mac: “Worlds” is damaged and can’t be opened

Cause: macOS shows this message for some unsigned apps downloaded from the internet, because it puts a quarantine mark on them. The file is not damaged if its fingerprint is right.

  1. Make sure you downloaded the file from the releases page on GitHub and its fingerprint matches SHA256SUMS.txt.
  2. Move the app into Applications if it is not there yet.
  3. Open Terminal and type the following command with a space at the end, without pressing Enter yet: 
    xattr -dr com.apple.quarantine
  4. Drag the app from Applications and drop it on the Terminal window, so its path is written after the command. Then press Enter.
  5. Open the app again. If you see the Not Opened message, follow the section above.

Android: the phone blocks the install

  • Not allowed to install unknown apps from this source: tap Settings and turn on Allow from this source for the app you opened the file from (Chrome or Files). The drawings are in the Android install steps.
  • Play Protect blocked the app: tap More details, then Install anyway.
  • Recent Samsung phones: the Auto Blocker feature blocks apps from outside the stores. Turn it off for a moment in Settings, then Security and privacy, then Auto Blocker, install, then turn it back on.
  • A message that your admin blocked this: the phone, or its work profile, follows an organization's policy. Use Worlds in the browser, or ask the admin.

Android: “App not installed”

  • An earlier Worlds is installed with a different signature: Android does not accept an update signed with another key. The only fix is to remove the old one and then install, and removing it deletes your pages from the phone. Export what you need first, as in Update and uninstall.
  • Android older than 8.0: a message about a problem parsing the package appears. Worlds needs Android 8.0 or later; use the browser instead.
  • Storage is full: free some space and try again.
  • The download did not finish: download it again and check its fingerprint.

iPhone and iPad: “Untrusted Developer” or “Untrusted Enterprise Developer”

Cause: the app is signed with your account, and you have not trusted that account on the device yet.

  1. Open Settings, then General, then VPN & Device Management.
  2. Under Developer App, tap your Apple ID email.
  3. Tap the Trust button, then confirm.

If there is no Developer App section, the app is not installed yet or was installed with another account. The drawings are in the iPhone and iPad install steps.

iPhone and iPad: “Developer Mode Required”

  1. Open Settings, then Privacy & Security, and scroll to Developer Mode under Security.
  2. Turn it on and tap Restart.
  3. After the restart, tap Turn On and enter your passcode.

The Developer Mode row does not appear until the first app signed this way is installed on the device. Install SideStore first by its guide, then come back.

iPhone and iPad: Worlds will not open after 7 days

Cause: with a free Apple ID the signature runs out after 7 days, and iOS refuses to open the app: it closes as soon as it opens, or a message says it is not available.

  1. Open SideStore, then My Apps.
  2. Tap the days button next to Worlds to refresh it, or refresh all apps at once. Follow what SideStore asks for to connect while refreshing.
  3. Open Worlds. Your pages are as they were, because an expired signature deletes nothing.

If SideStore itself has expired, install it again from the computer by its guide. If the tool says you reached the maximum number of apps, a free account allows three signed apps at once: remove one you do not need from My Apps. To avoid weekly refreshes altogether, a paid Apple Developer membership makes the signature last a year.

Browser: my pages disappeared

Cause: in the browser, your pages are kept in the browser's storage for app.enterworlds.space, unless you signed in.

  • A private or incognito window: it keeps nothing after you close it, and may refuse to save at all. Use a normal window.
  • Another browser or another device: each browser has its own copy. Go back to the browser you wrote in, or sign in there first so its pages move to your account.
  • You cleared browser data, or Safari deleted data of a site you had not opened for some days: the browser copy is gone. If you were signed in before that, sign in again and your pages come back from your account.

To avoid this, sign in with an account, or use one of the apps, which keep your pages on your device. Details in where your pages are kept.

The sign in code did not arrive

The code is sent from no-reply@enterworlds.space. It has 6 digits and works for 10 minutes.

  1. Check your spam or junk folder, and in Gmail the Promotions tab too.
  2. Search your mail for no-reply@enterworlds.space. If you find the message in spam, mark it as not spam so the next one reaches your inbox.
  3. Make sure the email you typed is right, with no missing letter or space.
  4. Wait a minute, then click Send a New Code, and use the code in the newest message only.
  5. Work and school mail may hold automated messages. Try a personal address, or ask the admin to allow the sender.

The fingerprint does not match SHA256SUMS.txt

Do not open the file. Most often the download did not finish. Delete it and download it again from the releases page on GitHub, then compare the fingerprint with the line carrying the same file name in the SHA256SUMS.txt of the same version. See the install overview.
