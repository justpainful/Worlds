Documents

A document is a page written on real paper: it has a size, margins, a header and a footer, and you see it as it will print. Use it for reports, letters and homework you will hand in on paper or as a PDF.

Document or page?

To create a document: New in the sidebar or on Home, then Document, or the New Document command in the command palette. A new document starts as A4 portrait.

The toolbar

From left to right:

  • Paragraph style: Normal, Title, Subtitle, Heading 1, 2 and 3, Quote, Caption.
  • Font: Default, then Instrument Sans, IBM Plex Sans Arabic, Segoe UI, Calibri, Arial, Tahoma, Georgia, Cambria, Times New Roman and Courier New.
  • Size: the Smaller and Larger buttons, and a menu with Document size and sizes from 8 to 72 points. Auto means the document size.
  • Bold (Ctrl + B), Italic (Ctrl + I), Underline (Ctrl + U), and Strikethrough.
  • Text colour: a Text section for the letter colour, and a Highlight section with Automatic, five markers and No highlight.
  • Alignment: Align left, Center, Align right, Justify.
  • Lists: Bulleted list, Numbered list, Checklist.
  • Line spacing: Document spacing, or 1, 1.15, 1.5 or 2.
  • Table: inserts a 3 by 3 table with a header row.
  • Clear formatting.

A document uses the same editor as pages, so each paragraph follows the direction of its text, and Arabic and English sit together in one document with no setup.

Page setup

Press Page setup at the top of the document. Under the title you see a summary of the current setup, such as "A4 · portrait".

Documents have no automatic page numbers yet. The header and footer are fixed text repeated as is on every page.

Printing and saving as PDF

  1. Press "Print or PDF"

    The button sits at the top of the document next to Page setup. It opens the Windows print window at the paper size and margins you chose.

  2. Choose the printer

    To print on paper, pick your printer. For a PDF file, pick a PDF printer such as Microsoft Print to PDF.

  3. Save

    Press Print, then choose where to save the file and its name if you are making a PDF.

Documents do not export to Word (docx) or HTML yet. Ordinary pages also have Copy as Markdown and Save as Markdown file. See Page tools.
