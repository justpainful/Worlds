Install Worlds

Pick your device, download one file from the releases page, then follow the steps on your device's page. To start without installing anything, open Worlds in your browser.

Next to these files is a small file called SHA256SUMS.txt (594 bytes). It holds a fingerprint of every file so you can check your download is intact. See the end of this page.

The two Mac files hold the same app. Download the .dmg, and use the .zip only if the .dmg does not open for you. Do not install the iPad file on an iPhone, or the other way round.

Requirements

Windows
Windows 10 or Windows 11, 64 bit (x64). Setup does not need an internet connection.
Android
Android 8.0 or later, on a phone or tablet.
iPhone and iPad
iOS or iPadOS 17 or later, an Apple ID, and a Windows PC or a Mac once, to set up the signing tool.
Mac
macOS 14 Sonoma or later.
Browser
A recent version of Chrome, Edge, Firefox or Safari.

The Windows app is the most complete. The Android app is close to it. The iPhone, iPad and Mac apps are an early version. The browser version is the same interface as Windows, but it keeps its pages in the browser.

Why you see a warning when installing

The Worlds files are not signed with a paid certificate from Microsoft or Apple, and the app is not in the stores yet. So:

  • Windows shows the blue SmartScreen window before setup, with a way to continue.
  • macOS blocks the app the first time until you allow it yourself.
  • The Android file is signed with a development key, so Android asks for permission to install apps from outside Google Play.
  • The iPhone and iPad files are unsigned, so a tool such as SideStore signs them with your own Apple ID.

Each install page walks through this step with a drawing of the window you will see. To be sure the file is the one that was published, follow the steps below.

Check the file with SHA256SUMS.txt

Each file has a SHA-256 fingerprint: 64 letters and digits that all change if a single byte of the file changes. Work out the fingerprint of the file you downloaded, then compare it with the line that carries its name in SHA256SUMS.txt. If they match, the file is intact.

  1. Download SHA256SUMS.txt

    Get it from the latest release page and save it in the same folder as the installer (usually Downloads). You can also open it in the browser and read it there.

  2. Work out the file's fingerprint

    On Windows: open PowerShell from the Start menu, paste this command and press Enter:

    Get-FileHash "$env:USERPROFILE\Downloads\Worlds-1.1.0-Windows-x64-setup.exe" -Algorithm SHA256

    The fingerprint appears in capital letters, and the file lists it in small letters. Case does not matter, only that they match.

    On a Mac: open Terminal and paste:

    shasum -a 256 ~/Downloads/Worlds-1.1.0-macOS-Unsigned.dmg

    On Linux, or Linux on a Chromebook: put both files in one folder and run:

    cd ~/Downloads
sha256sum -c SHA256SUMS.txt --ignore-missing

    The command prints OK next to each intact file.

    On a phone: Android and iOS do not work out fingerprints on their own. Download the file on a computer and check it there, or use an app you trust that computes SHA-256.

  3. Compare the two fingerprints

    Compare the result with the line that carries the file's name. These are the fingerprints of version 1.1.0, for comparison:
