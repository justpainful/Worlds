Install Worlds on Mac

You drag the app into Applications, then allow it to open once, because it is not signed by Apple. After that it opens like any other app.

Before you start

File
Worlds-0.3.2-macOS-Unsigned.dmg (26.6 MB), or Worlds-0.3.2-macOS-Unsigned.zip (22.5 MB) with the same app inside
System
macOS 14 Sonoma or later
Signing
Not signed or notarized by Apple, so macOS blocks it the first time
App name
Finder may show it as Worlds-macOS-Unsigned; it is Worlds

The Mac app is an early version. It opens a Worlds workspace file (worlds.db), shows pages, documents, tables, drawings and presentations, and edits them when the file is on the Mac's own disk. See what works on each platform.

Install step by step

  1. Download the dmg file

    Open the latest release page on GitHub and under Assets click Worlds-0.3.2-macOS-Unsigned.dmg. It goes to Downloads. You can check its fingerprint as shown in the install overview.

  2. Open the dmg file

    Double click it. A disk called Worlds appears in the Finder sidebar, and its window opens with the app icon.

  3. Drag the app to Applications

    Drag the app icon out of the disk window and drop it on Applications in the sidebar. The window has no Applications shortcut of its own, so use the sidebar.

    When it has copied, eject the disk: right click Worlds in the sidebar and choose Eject. You can delete the dmg file afterwards.

    If you downloaded the zip file: double click it in Downloads, the app appears next to it, then drag it to Applications as above.

  4. Open the app the first time

    Open Applications and double click the app. macOS blocks it because it is unsigned. What you do next depends on your macOS version: see About This Mac in the Apple menu.

Opening it the first time on macOS 15 Sequoia and later

  1. Click Done in the alert

    An alert says Worlds was not opened because Apple could not check it. Click Done. Do not click Move to Trash.

  2. Open Privacy & Security

    Open the Apple menu, then System Settings, then Privacy & Security in the sidebar. Scroll down to the Security section.

  3. Click Open Anyway

    You find a line saying Worlds was blocked to protect your Mac, with an Open Anyway button next to it. Click it. The line stays for about an hour after you tried to open the app; if it is not there, try opening the app again and come back.

  4. Confirm with your Mac password

    macOS asks one last time. Click Open Anyway again and enter your Mac account password or use Touch ID. Worlds opens, and macOS will not ask again.

Opening it the first time on macOS 14 Sonoma

  1. Right click the app and choose Open

    In Applications, right click the app (or click it while holding Control) and choose Open from the menu.

  2. Click Open in the alert

    macOS asks if you are sure, because it does not know the developer. Click Open. From then on Worlds opens straight away.

    If the alert has no Open button, use the Privacy & Security way instead; it works on macOS 14 too.

If macOS says the app is damaged and should be moved to the Trash, the file is not damaged. macOS shows this message for some unsigned apps. The fix is in Troubleshooting.

What you see the first time

Worlds opens in a window with a sidebar for moving around. The Mac app is built to open an existing Worlds workspace:

  • From the File menu choose Open Database…, or press Command + O, and pick the file worlds.db. The attachments folder should sit next to it.
  • To bring your workspace from a Windows PC: quit Worlds there from the notification area, then copy the whole %APPDATA%\Worlds folder to the Mac, into a folder on the disk, not in iCloud Drive.
  • Edits are saved into the file itself when it is on a local disk. In iCloud Drive or another cloud folder it opens read only, with a note that says why, and you can make an independent local copy of it.
  • The assistant chats with a provider you choose and an API key you enter in its settings; the key is kept in the Mac's Keychain. It does not edit pages yet.
