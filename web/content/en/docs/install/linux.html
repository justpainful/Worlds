Install Worlds on Linux

There are two files with the same app: an AppImage that runs on most distributions without installing, and a .deb package that installs it on Ubuntu, Debian and the systems built on them. Pick one.

Before you start

AppImage
Worlds-1.0.0-Linux-x86_64.AppImage (94.9 MB)
deb
Worlds-1.0.0-Linux-amd64.deb (20.6 MB)
System
64-bit Linux (x86_64) with WebKitGTK 4.1, which comes with Ubuntu 22.04 and later, Debian 12 and Fedora 39.
Where your pages live
~/.local/share/Worlds, with worlds.db and the attachments folder

With the AppImage

  1. Download the file

    On the latest release page on GitHub, under Assets, click Worlds-1.0.0-Linux-x86_64.AppImage.

  2. Make it executable

    In your file manager: right-click the file, open Properties, then Permissions, and turn on "Allow executing file as program". Or in a terminal:

    chmod +x ~/Downloads/Worlds-1.0.0-Linux-x86_64.AppImage

  3. Run it

    Double-click it, or run it by its path in a terminal. If you see an error about FUSE on Ubuntu 22.04 or later, install the library AppImages need:

    sudo apt install libfuse2

    On Ubuntu 24.04 the package is called libfuse2t64.

With the .deb package

  1. Download the package

    On the same release page, click Worlds-1.0.0-Linux-amd64.deb.

  2. Install it

    Open a terminal in your Downloads folder and run:

    sudo apt install ./Worlds-1.0.0-Linux-amd64.deb

    apt installs any missing libraries with it. Worlds then shows up in your applications menu.

Check the file

Put the file and SHA256SUMS.txt in one folder and run sha256sum -c SHA256SUMS.txt --ignore-missing. It prints OK next to a good file. More on the install page.

Removing it

AppImage: delete the file. deb: sudo apt remove worlds. Your pages stay in ~/.local/share/Worlds until you delete that folder yourself.
