الدليل / الرسم والعرض والوسائط

العروض التقديمية

اصنع شرائح بنص وصور وفيديو وأشكال، واختر لكل شريحة خلفيتها، ثم اعرضها بملء الشاشة وتنقّل بينها بلوحة المفاتيح.

إنشاء عرض

من زر جديد اختر عرض تقديمي، أو الأمر عرض تقديمي جديد من لوحة الأوامر. كل الشرائح بنسبة 16:9 (1280 في 720)، والعرض الجديد يبدأ بنمط داكن.

الشرائح

  • شريحة جديدة أسفل قائمة الشرائح: تختار تخطيطها من قائمة.
  • انقر شريحة بالزر الأيمن: شريحة جديدة بعدها، نسخ، حذف الشريحة.
  • اسحب الشرائح المصغرة لتغيير ترتيبها.
  • PageUp وPageDown للانتقال بين الشرائح أثناء التحرير.

التخطيطات

العنوان، عنوان ومحتوى، قسم، عمودان، صورة مع تعليق، فارغ. أماكن النص تعرض انقر لإضافة عنوان وانقر لإضافة عنوان فرعي وانقر لإضافة نص. وقائمة التخطيط موجودة أيضًا في شريط الأدوات لتغيير تخطيط الشريحة الحالية.

شريط الأدوات

  • Text box: مربع نص.
  • صورة: png أو jpg أو jpeg أو gif أو webp أو avif أو svg.
  • فيديو: mp4 أو webm أو mov أو m4v.
  • الشكل: مستطيل، دائرة، خط. للشكل المحدد زر التعبئة للونه.
  • قائمة التخطيط، ثم الخلفية (انظر أدناه).
  • تراجع (Ctrl + Z) وإعادة (Ctrl + Y).

عند تحديد نص تظهر أزرار تصغير الخط وتكبيره (من 14 إلى 120)، والعريض والمائل، ولون النص، والمحاذاة. وعند تحديد أي عنصر: ترتيب (إحضار إلى الأمام، تقديم للأمام، إرجاع للخلف، إرسال إلى الخلف)، ونسخه (Ctrl + D)، وحذف.

خلفية الشريحة

زر الخلفية في شريط الأدوات يفتح قائمة فيها:

  • عشرة ألوان ثابتة، تظهر برموزها مثل #16161a و#ffffff: داكن، كحلي، أخضر داكن، خمري داكن، عاجي، أبيض، أزرق، بنفسجي، بني محمر، أخضر.
  • صورة…: صورة من جهازك (png أو jpg أو jpeg أو webp أو avif).
  • إزالة الصورة.

لا توجد تدرجات لونية للخلفية حاليًا.

ملاحظات المتحدث

تحت الشريحة مربع ملاحظات المتحدث. اكتب فيه ما تريد قوله، ولن يظهر للجمهور إلا إذا أظهرته بنفسك أثناء العرض بالمفتاح N.

العرض بملء الشاشة

اضغط عرض أعلى المحرر أو F5. تملأ الشريحة الشاشة، ويظهر في الزاوية رقم الشريحة من المجموع، مثل «1 / 3».

المفاتيحما تفعله
السهم الأيمن أو السفلي، PageDown، المسافة، Enter، أو نقرةالشريحة التالية
السهم الأيسر أو العلوي، PageUp، Backspaceالشريحة السابقة
Home وEndالشريحة الأولى والأخيرة
Nإظهار ملاحظات المتحدث أو إخفاؤها
Escإنهاء العرض

لا توجد شاشة مقدّم منفصلة، ولا تصدير للعرض إلى PDF أو PowerPoint حاليًا.
