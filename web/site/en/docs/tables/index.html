Tables and spreadsheets

Worlds has two kinds of table: a full Spreadsheet with sheets and formulas, like Excel, and a simple Table inside a page for laying out text. This page explains both and lists every function the spreadsheet understands.

Which table do you need?

Table in a pageSpreadsheet
Creating"/" then TableNew then Spreadsheet
FormulasNoYes, 92 functions
Several sheetsNoYes
CSV and ExcelNoImport and export
ChartA Chart block on the same pageNo

The spreadsheet

Create one with New, then Spreadsheet, or the New Spreadsheet command in the command palette. A new sheet starts with 60 rows and 26 columns and grows when you insert rows or columns.

At the top

  • Templates: three ready-made spreadsheets: Financial Budget & Cashflow, KPI & OKR Tracker and Weighted Calculator & Matrix.
  • Import .xlsx / .csv.
  • Export: Export Excel (.xlsx) or Export CSV (.csv).
  • Shortcuts: the spreadsheet shortcut list, also opened with F1.

Cell tools

  • Undo and Redo.
  • Number Format: General / Auto, Number (1,234.56), Integer (1,235), Currency (SAR 1,234.56), Currency ($1,234.56), Accounting ((1,234.56)), Percent (12.3%), Scientific (1.23E+03).
  • Decrease Decimals and Increase Decimals.
  • Text Color, Cell Background Fill, Wrap Text.
  • AutoSum (Alt+=).
  • Sort Column A → Z and Sort Column Z → A, and Toggle AutoFilter.
  • Freeze Panes: Freeze Top Row, Freeze First Column, Unfreeze Panes.
  • Insert Row Above, Insert Column Left, Delete Row, Delete Column, Auto-fit Column Width. A sheet always keeps at least 10 rows and 5 columns.
  • Find & Replace (Ctrl+F).
  • Insert Function: a list of common functions with a short explanation of each.

Sheets

Sheet tabs sit at the bottom, with Add Sheet, and Rename Sheet, Duplicate Sheet and Delete Sheet.

Cell references

TypeMeaning
A1Column A, row 1.
A1:B5A range from A1 to B5.
$A$1, A$1, $A1A fixed reference that does not change when copied: fully, row only, or column only.
Sheet1!A1A cell on another sheet.
'Sheet 1'!$A$1A sheet whose name has a space: put the name in single quotes.

Sheet names can be in Arabic, and upper or lower case does not matter. While typing a formula, press F4 to cycle a reference through $A$1, A$1, $A1 and A1. In the Name Box, type A1 or A1:D10 and press Enter to jump there. The largest row a reference accepts is 100000.

Formulas

A formula starts with =, like =SUM(B2:B10). Separate arguments with a comma , or a semicolon ;. Text goes in double quotes, and TRUE and FALSE are logical values.

Import and export (CSV and Excel)

Import

  1. Press "Import .xlsx / .csv"

    It accepts .xlsx, .xls, .csv and .tsv files.

  2. Choose the file

    All sheets are read, formulas stay formulas, and dates become YYYY-MM-DD.

Importing replaces the whole spreadsheet with the file's content, all sheets included. To keep the current data, create a new spreadsheet and import into it.

Export

  • Export CSV (.csv): exports the current sheet only, as calculated values rather than formulas, with commas between columns, in UTF-8 so Arabic is kept. The file is named after the spreadsheet title.
  • Export Excel (.xlsx): exports all sheets and keeps the formulas. Sheet names are cut to 31 characters, the Excel limit.

Tables inside pages

Type "/" then Table for a 3 by 3 table with a header row. When you select cells, a bar appears with + Row, + Column, Delete row and Delete column. From the block handle: Add Row Below, Add Column Right, Toggle Header Row, Delete Table.

The Chart block draws a pie, bar or line chart from a table on the same page. The Collection, Board and Gallery blocks show subpages as a table with their properties. See Properties.
