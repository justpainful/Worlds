Install Worlds on Android

You download one APK file, allow your browser to install apps from outside Google Play once, then install. The file works on phones and tablets.

Before you start

File
Worlds-1.0.0-Android-Universal.apk
Size
29.5 MB
System
Android 8.0 or later
Signing
Signed with a development key, not from Google Play
Your pages
Inside the app on the device. Uninstalling the app deletes them, and they are not part of Google's backup.

The button names in the drawings are those of stock Android. They may differ a little on Samsung, Xiaomi and other phones, but the steps are the same.

Install step by step

  1. Download the file on the phone

    Open the latest release page in Chrome on the phone. Under Assets, tap Worlds-1.0.0-Android-Universal.apk. If Chrome says this type of file can harm your device, tap Download anyway.

  2. Open the file

    When it finishes, tap Open in the download notification, or open the Files app, then Downloads, and tap the file.

  3. Tap Settings

    The first time, Android says it is not allowed to install unknown apps from this source. The source is the app you opened the file from, Chrome or Files. Tap Settings.

  4. Turn on Allow from this source

    The Install unknown apps page opens for that app. Turn on Allow from this source, then go back with the back button.

  5. Tap Install

    Android asks: Do you want to install this app? Tap Install, wait for it to finish, then tap Open.

  6. If a Play Protect window appears

    Google Play Protect may scan the app because it comes from outside the store. If it says it blocked the install, tap More details, then Install anyway. If it offers to send the app for a scan, you can accept or decline; it does not change the install.

  7. Turn the permission off again (optional)

    After installing, you can go to Settings, then Apps, then Special app access, then Install unknown apps, and turn it off for Chrome. Worlds stays installed. You will need the permission again to update.

What you see the first time

Worlds is in your app list. It opens on Home; your pages are kept inside the app on the phone and work offline. The interface is in Arabic when the phone's language is Arabic.

  • An account is not required. When you want shared workspaces, you sign in with your email and a code sent from no-reply@enterworlds.space.
  • The assistant chats, edits pages and adds tasks, with an API key from a provider you choose or a server on your computer such as Ollama. The key is stored encrypted with a key in the Android Keystore.
  • The Tasks, Goals, Inbox and Calendar screens are in the sidebar, and Study appears when the Study pack is on.

On a Chromebook

ChromeOS does not let you open an APK directly. The official way goes through the developer tools and suits people who know Terminal. It is easier to use Worlds in the browser.

Turning on ADB on a Chromebook restarts it, and turning it off later needs a factory reset (Powerwash) that erases everything on the device. School and work Chromebooks may block it.

  1. Turn on Linux and ADB

    Open Settings, then Advanced, then Developers, and turn on the Linux development environment. Then under Develop Android apps, turn on Enable ADB debugging and restart.

  2. Install the file from Terminal

    Copy the APK into Linux files, open Terminal and run:

    sudo apt install adb
adb connect arc
adb install Worlds-1.0.0-Android-Universal.apk

    If ChromeOS asks to allow debugging, allow it. Worlds then appears in the launcher.

If something goes wrong

  • Android blocks the installThe source permission, Play Protect, and work phones.
  • App not installedA clash with an earlier version, or an old Android version.
