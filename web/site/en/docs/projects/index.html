Projects and resources

Everything you create in Worlds is a "resource": a page, document, spreadsheet, presentation, drawing, gallery, file and more. A project brings the resources for one piece of work together in one place.

Kinds of resource

KindForGuide
PageNotes, ideas and anything in blocksPages
DocumentA formatted document on paper pagesDocuments
SpreadsheetTables, formulas and sheetsTables
PresentationSlides to presentPresentations
DrawingDraw, edit images and explain visuallyDrawing
ProjectGathers documents, files and pagesOn this page
GalleryPhotos, videos and GIFsThe gallery
FileA picture, video, PDF or document from your PCFiles
StreamA video stream link such as m3u8Streams
Task, Event, Capture, GoalTasks, calendar, inbox and goalsQuick add
Subject, Lesson, Assignment, Exam, To bringOnly with the Study packStudy

Creating a resource from the sidebar

Press New at the top of the sidebar (or on Home) to open the create menu. In order:

  1. Page (Ctrl + N), Document, Spreadsheet, Presentation, Drawing, Project, Gallery.
  2. Task, Event, Quick Capture (Ctrl + Alt + N), and Subject with the Study pack.
  3. Upload Files: each file becomes its own File resource. And Add Stream Link.

Pages, documents, spreadsheets, presentations, drawings, projects, galleries and files show in the Pages tree. If you create a resource with the New button inside a project, it is created under that project.

The resource header

Every resource has a header with its icon (Change icon), its title, its kind and last edit time, a Pin button and a More button. The More menu holds New Subpage, Pin, Favorite, Duplicate, Move to, Share, Save as Template, Archive, Delete.

The project

A project gathers what belongs to one piece of work: a research paper, a science fair, a customer order. Create one with New, then Project.

Project details

  • Status: Planned, Active, Paused, Done.
  • Start and Due.
  • A short description: What is this project about?
  • The project's tasks, with an Add a task in this project field.

Two ways to gather resources

Inside the projectLinked to the project
HowThe New button in the project headerLink existing in the Linked section
Where the resource livesUnder the project in the treeIn its own place; the project just points to it
How it showsGrouped by kind: documents, presentations, drawings, pages, galleries, filesCards in the Linked section, each with Unlink

With Link existing you type in Find something to link and pick. At the bottom of the project, the Activity section lists the latest changes to its resources.

Study items

Subjects, lessons, assignments and exams belong to the Study pack, which is off to start with. Turn it on in Settings, then Packs, or from the Home question Do you use Worlds for school or university? with Turn on Study. Turning the pack off hides its items without deleting them. See Packs.

Once it is on, Study appears in the navigation, and a Subjects section appears in the sidebar with New subject.

The Study page

It shows Today's classes, Due in the next two weeks and Subjects. If you have no subjects yet, you start with Set up your subjects.

A subject

  • Teacher, Room, Code (such as CHEM 101), Colour.
  • Timetable: add a Class time so its weekly classes show in the Calendar.
  • Assignments: homework is called an "assignment" here. The add field understands dates, such as "Lab report sunday".
  • Exams: the same way, such as "Midterm 24/11 8am".
  • To bring or print: things to bring or print, such as "Calculator tomorrow".
  • Tasks, Textbooks & Solution Books, and resource links (YouTube, Telegram, Classroom, مدرستي).
  • Lessons: the Lesson notes button creates a lesson page under the subject.
  • The subject header shows the Average from graded work. To delete it, use Delete subject.
