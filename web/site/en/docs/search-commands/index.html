Search and commands

Press Ctrl + K to search all your pages or run any command without leaving the keyboard. Type tasks in plain words, such as "Call the bank tomorrow 4pm", and Worlds understands the date and time, in English and in Arabic.

The command palette

KeysOpens
Ctrl + KPages and commands together. Press it again to close.
Ctrl + PPages only: Go to a page.
Ctrl + Shift + PCommands only: Run a command.

You can also open it with the Search button in the sidebar or on Home, or by right-clicking an empty spot and choosing Search and Commands. If you select text and right-click, Search Worlds searches for it.

Inside the palette

  • Before you type: Recent (the last 6 resources you opened), then commands.
  • Type to search, and use the Up and Down arrows to move.
  • Enter: Open. Ctrl + Enter: New tab. Alt + Enter: Open right. Esc: close.
  • If nothing matches, you are offered Create a page with the name you typed.

Trash

When a page is open you also get New Subpage, Pin Page or Unpin Page, Insert Image, Insert File, Send to Discord, Assistant Instructions, Page History, Duplicate Page, Save Page as Template, and Archive Page or Unarchive Page. With the Study pack: Study and New Subject.

Search

Search in the palette looks in:

  • Page titles and the text of every block.
  • The names of attached files, not their contents.
  • Text in drawings and drawing library tags.
  • Other fields: project descriptions, document headers and footers, task notes, event locations, subject teachers and rooms, assignment instructions, and spreadsheet sheet names and cell values.

Search finds a word even inside a longer word, which suits Arabic. With several words, you get results that contain all of them, and title matches come first. Pages in Trash do not show; archived pages do. Templates show too: picking one creates a new page from it.

Find in a page

Ctrl + F opens Find in page, and Ctrl + H adds Replace with. The Aa button matches case, then Replace or All. Enter goes to the next match, Shift + Enter to the previous one, and Esc closes.

Quick capture and quick add

Quick capture

Ctrl + Alt + N from anywhere in Worlds opens Quick capture. Type anything and press Enter (or Save); Shift + Enter adds a new line.

  • Normally the text is saved as is to the Inbox, to sort out later.
  • With Save as a task ticked, the date, time and priority are read from the text and a task is created.

In the Inbox, each item has Task, Event and Page buttons to turn it into one of those; Task and Event read the date from the text.

Quick add fields

These fields understand dates and times and show what they understood before you save: in Tasks, in Calendar (a one-hour event if you give a time, otherwise all day), Add a task for today on Home, project tasks, goals, and a subject's assignments, exams and things to bring.

What it understands

tonight, الليلةToday, at 8 pm if you give no time
tomorrow, tmr, tmrw, بكرة, بكره, غدا, غدًاTomorrow
after tomorrow, بعد بكرة, بعد غدIn two days
next week, الأسبوع الجاي, الأسبوع القادمIn 7 days
in 3 days, in 2 weeks, بعد 3 أيام, بعد 2 أسابيعAfter that long. Write the number in digits
Weekdays: sunday or sun to saturday, on mon, next mon, and Arabic الأحد to السبت (with or without «ال», optionally after «يوم»)The next day with that name, never today
2026-12-05That date
5/12Day first, then month: 5 December. If it has passed, next year
4pm, 5:30, 5:30pm, 17:00, at 9:30, الساعة 5 مساء, 9 صباحاThe time. "at 5" on its own means 05:00
!, !!, !!!, or !1, !2, !3Priority

The words it understands are removed from the title. A time with no date means today, or tomorrow if that time has passed. It does not understand month names, "next month" or tags yet.

A weekday name in the title is always read as a date. "Read Monday Morning", for example, becomes "Read Morning" due on Monday. If that is not what you meant, fix the title or the date after saving.
