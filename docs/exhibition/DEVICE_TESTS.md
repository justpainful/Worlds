# قائمة تجربة الأجهزة قبل المعرض

جرّب كل جهاز بالترتيب، وعلّم على كل خطوة نجحت. إذا خطوة ما حصلت مثل المتوقع: صوّر الشاشة، واكتب رقم الخطوة واسم الجهاز، وأرسلها لي. ما أفتح issue في GitHub إلا بعد موافقتك.

اتبع خطوات [قصة العرض الحي](DEMO_SCRIPT.md) على كل جهاز يدعمها، فهذه القائمة تتأكد أن العرض نفسه يمشي.

## 1. ويندوز نظيف بدون إنترنت (جهاز المعرض)

جهّز: مثبّت ويندوز من مسار Windows installer على USB، ومثبّت Ollama مع نموذج محلي محمّل مسبقًا (مثل llama3.2 أو qwen2.5). افصل الإنترنت قبل البدء.

| # | الخطوة | المتوقع |
| :--- | :--- | :--- |
| 1.1 | شغّل المثبّت من USB. | يظهر تحذير SmartScreen لأن المثبّت غير موقّع: اضغط «مزيد من المعلومات» ثم «تشغيل على أي حال». يكتمل التثبيت بدون إنترنت. |
| 1.2 | افتح Worlds أول مرة. | تظهر شاشة الترحيب والجولة. لا رسالة خطأ عن WebView2 أو الشبكة. |
| 1.3 | من الإعدادات، ثم المظهر: اختر العربية. | الواجهة كلها بالعربي، والشريط الجانبي على اليمين. |
| 1.4 | من الإعدادات، ثم التخزين: اضغط «تحميل» في مساحة العمل التجريبية. | تظهر «مساحة طالب تجريبية» فيها صفحات ومادتان وجدول درجات ورسمة وعرض. |
| 1.5 | افتح «درجات الفصل» وعدّل درجة. | يتغير المعدل مباشرة. |
| 1.6 | افتح «رسم الخلية النباتية» وارسم خطًا بالماوس، ثم حدد عدة أجزاء واسحبها. | الخط يظهر بسلاسة، والأجزاء تتحرك معًا. |
| 1.7 | ثبّت Ollama وشغّله، ثم من الإعدادات، ثم المزوّدون: تأكد أنه «يعمل». | يظهر Ollama بحالة «يعمل» ويظهر النموذج المحلي. |
| 1.8 | افتح Claude من الشريط الجانبي، واختر Ollama من زر النموذج، واطلب: «لخّص صفحة خطة الأسبوع في ثلاث نقاط وأضفها في أعلى الصفحة.» | يرد النموذج بدون إنترنت، وتتعدل الصفحة. |
| 1.9 | اضغط «تراجع». | يرجع آخر تعديل. |
| 1.10 | صغّر النافذة وكبّرها، وافتح قائمة المساحات أعلى الشريط الجانبي. | لا تظهر أزرار ويندوز صغيرة إضافية، والقائمة واضحة فوق الشريط. |
| 1.11 | اقفل Worlds وافتحه من جديد. | تبقى كل التعديلات. |

## 2. جوال أندرويد

جهّز: ملف APK من صفحة الإصدارات، والسماح بالتثبيت من مصادر خارجية.

| # | الخطوة | المتوقع |
| :--- | :--- | :--- |
| 2.1 | ثبّت الـ APK وافتح Worlds. | يفتح التطبيق بدون أخطاء. |
| 2.2 | اجعل لغة الجوال عربية (أو من إعدادات التطبيق). | الواجهة بالعربي ومن اليمين لليسار. |
| 2.3 | أنشئ صفحة واكتب فيها فقرة بالعربي وفقرة بالإنجليزي. | كل فقرة باتجاهها الصحيح. |
| 2.4 | أضف مهمة لليوم، ثم علّمها منجزة. | تظهر في المهام ثم تنتقل للمنجزة. |
| 2.5 | أنشئ رسمة وارسم بإصبعك. | الرسم يتبع الإصبع بدون تأخير ظاهر. |
| 2.6 | أغلق التطبيق تمامًا وافتحه. | يبقى كل ما أنشأته. |
| 2.7 | شغّل وضع الطيران وعدّل الصفحة، ثم أوقفه. | يقبل التعديل بدون إنترنت. |

## 3. آيباد

جهّز: نسخة TestFlight أو نسخة مثبتة من Xcode.

| # | الخطوة | المتوقع |
| :--- | :--- | :--- |
| 3.1 | افتح Worlds. | يفتح بالشريط الجانبي والصفحة الرئيسية. |
| 3.2 | اجعل لغة الآيباد عربية. | الواجهة بالعربي ومن اليمين لليسار. |
| 3.3 | أنشئ صفحة واكتب فيها. | الكتابة سلسة، والصفحة تُحفظ. |
| 3.4 | أنشئ رسمة وارسم بالقلم ثم بالإصبع. | يتأثر الخط بضغط القلم. |
| 3.5 | أدر الآيباد عموديًا وأفقيًا. | يتكيف التصميم بدون عناصر مقصوصة أو متداخلة. |
| 3.6 | اقفل التطبيق وافتحه. | يبقى كل ما أنشأته. |

## 4. ماك مع مفتاح مزوّد حقيقي

جهّز: إنترنت، ومفتاح API لمزوّد واحد على الأقل (Anthropic أو OpenAI).

| # | الخطوة | المتوقع |
| :--- | :--- | :--- |
| 4.1 | افتح Worlds. | يفتح بدون أخطاء. |
| 4.2 | من إعدادات المزوّدين، أضف المفتاح. | يظهر المزوّد بحالة «جاهز». |
| 4.3 | افتح المساعد واطلب: «أنشئ صفحة فيها خطة مذاكرة لأسبوع.» | يرد ويُنشئ الصفحة فعلًا. |
| 4.4 | افتح الصفحة الجديدة وعدّلها. | التعديل يُحفظ. |
| 4.5 | جرّب اللغة العربية من إعدادات النظام. | الواجهة بالعربي ومن اليمين لليسار. |

## 5. نسخة الويب من رمز QR (جوال أي زائر)

جهّز: رابط نسخة الويب بعد نشرها، ورمز `qr.svg` مطبوعًا.

| # | الخطوة | المتوقع |
| :--- | :--- | :--- |
| 5.1 | امسح الرمز بكاميرا الجوال. | تفتح نسخة الويب في المتصفح. |
| 5.2 | انتظر التحميل. | تظهر مساحة العمل التجريبية والجولة، والشريط الجانبي فوق الصفحة. |
| 5.3 | اضغط عنصرًا في الشريط الجانبي. | يفتح العنصر وينغلق الشريط، والصفحة بعرض الشاشة كاملًا. |
| 5.4 | اضغط زر إظهار الشريط الجانبي أعلى الصفحة. | يرجع الشريط فوق الصفحة. |
| 5.5 | من الإعدادات، ثم المظهر: اختر العربية. | الواجهة بالعربي، والشريط يفتح من اليمين. |
| 5.6 | أغلق التبويب وافتح الرابط من جديد. | تبدأ نسخة جديدة نظيفة، وهذا متوقع: نسخة الويب لا تحفظ شيئًا بعد إغلاق التبويب. |

## بعد التجربة

- أرسل لي كل خطوة فشلت، مع صورة ورقم الخطوة واسم الجهاز.
- أصلح كل مشكلة على فرع المعرض، ثم تعيد أنت تجربة نفس الخطوة.
