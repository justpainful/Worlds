# Worlds 0.3.0 (مسودة)

نسخة المعرض: ذكاء اصطناعي حقيقي على كل المنصات، وواجهة عربية كاملة، ومساحة عمل تجريبية.

## التحميل

| المنصة | الملف | ملاحظة |
| :--- | :--- | :--- |
| ويندوز | `Worlds-0.3.0-Windows-x64-setup.exe` | فيه WebView2، فيتثبت بدون إنترنت |
| أندرويد وكروم بوك | `Worlds-0.3.0-Android-Universal.apk` | موقّع بمفتاح تطوير |
| آيفون وآيباد | `Worlds-0.3.0-iPhone-Unsigned.ipa` و`iPad` | يحتاج توقيعًا بأداة مثل SideStore |
| ماك | `Worlds-0.3.0-macOS-Unsigned.dmg` | افتحه أول مرة بالزر الأيمن ثم Open |

## الجديد

- **الذكاء الاصطناعي في ويندوز:** Claude Code أو Codex (تسجيل الدخول بحساب ChatGPT)، أو مفتاح API من Anthropic وOpenAI وGemini وGroq وDeepSeek وMistral وxAI وOpenRouter، أو نموذج على جهازك مثل Ollama وLM Studio يعمل بدون إنترنت. يعدّل الصفحات بأدوات Worlds، وكل تعديل يمكن التراجع عنه.
- **الذكاء في الجوال والآيباد والماك:** محادثة حقيقية بنفس المزودين، والمفاتيح محفوظة في Keystore وKeychain. لا يعدّل الصفحات بعد.
- **واجهة عربية كاملة في ويندوز:** من اليمين لليسار، مع التواريخ والقوائم.
- **مساحة عمل تجريبية:** أسبوع طالب بالعربي والإنجليزي يتحمّل بضغطة، ونسخة عرض تعمل في المتصفح.
- **الرسم في آيفون وآيباد وماك:** الممحاة والأقنعة والمؤثرات والطبقات المتداخلة، وكل أنواع الفرش والأشكال، بألوان sRGB مطابقة لويندوز.
- **الدراسة والتخطيط في أندرويد:** شاشات للمهام والتقويم والمواد مع الدروس والواجبات والاختبارات، وإضافة سريعة تفهم مثل «tomorrow 4pm» و«بكرة».
- **الجداول في آيفون وآيباد وماك:** قيم محسوبة بمحرك الصيغ نفسه في ويندوز وأندرويد، وتعديل في النسخة المحلية.
- **الأتمتة في أندرويد:** ملخص بالذكاء الاصطناعي عبر المزود المختار، وإشعار على الجهاز بجانب ديسكورد.
- **إصلاحات:** سحب عدة خطوط محددة في رسم أندرويد، والقوائم المنبثقة لا تخرج من الشاشة، وبصمة SHA-256 لمثبّت ويندوز.

التفاصيل لكل ميزة في [مصفوفة أبل](../apple-native/FEATURE_PARITY_MATRIX.md) و[مصفوفة أندرويد](../android-native/FEATURE_PARITY_MATRIX.md).
