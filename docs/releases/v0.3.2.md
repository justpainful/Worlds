# Worlds 0.3.2 (مسودة)

إصلاح ما أبلغ عنه المستخدمون في الرسم وخرائط المفاهيم، وملف شخصي عام لكل حساب، وكل ما في 0.3.1 التي لم تُنشر.

## التحميل

| المنصة | الملف | ملاحظة |
| :--- | :--- | :--- |
| ويندوز | `Worlds-0.3.2-Windows-x64-setup.exe` | فيه WebView2، فيتثبت بدون إنترنت. غير موقّع، فاضغط «مزيد من المعلومات» ثم «تشغيل على أي حال» |
| أندرويد وكروم بوك | `Worlds-0.3.2-Android-Universal.apk` | موقّع بمفتاح تطوير |
| آيفون وآيباد | `Worlds-0.3.2-iPhone-Unsigned.ipa` و`iPad` | يحتاج توقيعًا بأداة مثل SideStore |
| ماك | `Worlds-0.3.2-macOS-Unsigned.dmg` | `Worlds.app` بتوقيع محلي، اسحبه إلى Applications |
| الويب | [app.enterworlds.space](https://app.enterworlds.space) | بحسابك، أو [demo.enterworlds.space](https://demo.enterworlds.space) بدون حساب |

## الجديد

- **الرسم على الشاشة:** يسألك «هل تريد نقل هذه اللوحة إلى الشاشة؟» وتظهر اللوحة فوق الشاشة وتقدر تحركها. شريط واحد عائم فيه تسعة أنواع فرش (خط، رصاص، بخاخة، ألوان مائية...)، وسهم بجانب اللون يفتح HEX وRGB والشفافية، وأشكال وتصحيح للأشكال.
- **أدوات الرسم:** أيقونات ملونة لكل أداة مثل الممحاة الوردية، والقوائم كلها بقوائم Worlds نفسها بدل القوائم البيضاء، ولا يمكن البدء بالرسم خارج اللوحة.
- **لوحة جديدة:** زر الفأرة الأيمن ثم «لوحة جديدة» يضيف لوحة بجانب الأخيرة بدل فتح صفحة.
- **النص العربي:** التاء المربوطة وآخر الحروف لا تنزل وحدها إلى سطر جديد.
- **خرائط المفاهيم:** عالم ثنائي الأبعاد تتحرك فيه بالسحب والتكبير، على ويندوز والويب وأندرويد وآيفون وآيباد وماك.
- **الملف الشخصي العام:** انشر ملفك على `profile.enterworlds.space/@اسمك` بصورتك وبانرك (حتى 25 ميغابايت، وGIF متحرك) وروابطك وكتلك، وأخفه أو احذفه متى شئت.
- **من 0.3.1:** عربية كاملة من اليمين لليسار على كل الأجهزة، والبحث يجد الكلمة مهما كُتبت الألف والتاء المربوطة، وجولة تعريفية، وصفحات HTML، وحزم القطاعات، وأدوات تخطيط الدراسة لـ Claude.

التفاصيل في [ملاحظات 0.3.1](v0.3.1.md) و[إصلاحات بلاغات المستخدمين](https://github.com/justpainful/Worlds/pull/8).
