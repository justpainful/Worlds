# Experimental attachment export

The original `src/resources/views/FileView.tsx` opens an attachment in its associated application or reveals it in its folder. It previews images, videos and formats supported by `src/editor/views/FilePreview.tsx`. `src-tauri/src/store/attachments.rs` stores the attachment record and a relative path under the attachments directory, with an original maximum size of 1 GiB. These operations are not all ported.

The isolated `OpenedDocumentPreviewView` can offer the system file exporter for the original bytes of a successfully opened image or PDF. The bytes come from the already-open attachment descriptor, not a second path lookup; export does not re-encode the image or reconstruct the PDF. The user chooses the destination through the system dialog. The preview's existing 64 MiB read limit also applies to export. Unsupported, locked, damaged, inaccessible or size-mismatched files do not receive an export button. The model clears its copy on close; a system export already in progress may retain its own copy until the dialog completes.

This is experimental and is not connected to the shipping app. `PersonalDocumentView` remains behind its debug flag; the standard independent database copy does not contain attachments. Identity and access checks around the original folder are not atomic against a process with the same user privileges, do not provide a live collaboration ACL lease, and cannot guarantee that an open file's contents have not changed in place during reading. This path must not be treated as an authorization boundary for shared pages. A selected export destination can be an existing file; the operating system's dialog governs overwrite confirmation.

Model tests cover original PDF bytes, release on close, and refusal on size mismatch. Apple build, the file exporter interaction, real security-scoped destinations, cancellation, overwrite behavior, accessibility and visual layout remain unverified. Full support for larger files, all source formats, import, native open/reveal behavior and synchronized attachments remains outstanding.
