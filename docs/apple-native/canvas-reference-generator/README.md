# Canvas reference provenance

These 64 by 64 transparent PNGs were produced by the existing `DrawingRenderer.render` from `src/drawing/renderer.ts` in headless Chrome, using its Canvas backend with viewport caching and background disabled. `index.html` constructs the actual scenes and writes base64 PNGs to the result element. `entry.ts` exports the original renderer and model into that page. A bundler plugin redirected only the application API import `../lib/api` to `api-stub.ts`; no attachments, workers or external services are used by these scenes. The test source and renderer must be re-audited when regenerating. The four single-stroke samples include varying pressure, flow and brush opacity; `layers.png` combines two translucent source-over layers. These are source output images, not claims about correctness or equivalence.

An isolated XCTest in `WorldsDrawingVisualComparisonTests` computes normalized mean absolute RGBA error for the four single-stroke references and the layer reference, with a strict 0.02 threshold. It remains outside Package.swift until configured with copied `CanvasReferences` resources on an Apple runner. Image orientation, color management and the threshold must be reviewed against the actual captured native images. The test records mean error, maximum channel error and changed-pixel count, and attaches the source and native PNGs. No comparison has run on Apple yet, and no numerical result or visual equivalence is claimed.
