# Personal image and PDF preview experiment

`PersonalDocumentView` is an unconnected DEBUG-only route for an existing personal file page, not for the independent copy that omits attachments. It asks the user for the folder containing the already-open `worlds.db` and `attachments`, checks database device and inode against the identity captured when opening the library, reads the personal file attachment, opens it with `openat`/`O_NOFOLLOW`, rechecks its database row and transfers the same descriptor to `OpenedDocumentPreviewView`. The scope lease outlives preview. The view accepts images and PDF by extension and verifies the bytes through ImageIO or PDFKit. The document reader limits reads to 64 MiB and source images to 64 million pixels, initially downsampling to at most 2048 pixels. On zoom it requests higher detail from the already-read bytes, reaching original dimensions when the image fits a 16-megapixel decoded-image target. Larger images are capped to that target and a visible notice explains the limit. Animated images show only the first frame. Locked PDFs show a clear unsupported message and PDFs above 1000 pages are refused. ImageIO and PDFKit can allocate additional memory internally; the input and output-pixel limits are not hard peak-memory guarantees. During image resolution replacement both decoded versions may coexist. A single higher-resolution decode runs at a time, coalescing requests.

The opened-file model checks the descriptor size against the recorded attachment size and also checks the number of bytes read before decoding. This does not prove content immutability: another process with access to the same inode can alter bytes without changing their length. Database path identity checks before and after asynchronous operations are not atomic against a malicious swap and swap-back, and a page becoming shared after authorization does not immediately revoke an already-open preview. These checks rely on the user's selected folder and normal system permissions, not an adversarial same-user boundary. The view does not authorize a shared page, reopen the path for sharing, edit the document, export it, or support the other file types. Cancellation suppresses the result and releases unclaimed descriptors; a read already running may continue until it returns. No claim of full file/media parity is made.

`OpenedDocumentModelTests` uses synthetic files to check a replaced path, PDF decoding, mismatched length, truncation after opening, initial downsampling followed by full-size loading within the output-pixel budget, a password-protected PDF, and closing before load. These tests and actual image/PDF visual screenshots require Apple CI and have not been run here.
