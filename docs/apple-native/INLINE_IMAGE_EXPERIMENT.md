# Experimental inline image opening

The original `src/editor/extensions/nodes.ts` image node stores an attachment ID, filename, caption and presentation attributes. `src/editor/views/MediaViews.tsx` displays the image in the page and supports actions including opening and revealing the attachment. This experiment is not feature parity: it presents the name and caption in the reader and opens a native preview only on request; it does not render the image inline, support nested image nodes, image resizing, annotation, external opening, reveal, sharing or export.

The entry point is restricted to debug builds with `WORLDS_EXPERIMENTAL_PERSONAL_DOCUMENT` and `WORLDS_EXPERIMENTAL_INLINE_IMAGE`. Neither flag is enabled for the shipping product. It is unavailable for imported database-only copies, which do not contain attachments. The user must choose the folder containing the selected database and attachments. The preview checks the original database identity, resolves the root image block and its same-page attachment in a SQLite read transaction, rejects shared or workspace pages, malformed or duplicate JSON keys, and checks the record again after opening the file. It checks size and format, uses the no-follow attachment vault and passes the open descriptor into the image preview.

These checks do not establish an atomic relationship between SQLite, file contents and authorization. A process with equivalent privileges can race path or database changes or restore file modification times, and access can change after the snapshot; no live collaboration ACL lease exists. Cross-page attachment references and nested images are intentionally unavailable. The image decoder has size and resolution limits and animated images show only the first frame. User cancellation or any failed check leaves the image unopened.

Synthetic SQLite coverage checks matching ownership, duplicate keys, malformed content, incompatible node type and shared metadata. The SQL was also exercised independently against a temporary v1 fixture. Swift tests, complete user-driven folder selection, image decoding through this route, accessibility and visual behavior on Apple have not been verified. Do not enable the flag before independent review and end-to-end tests.
