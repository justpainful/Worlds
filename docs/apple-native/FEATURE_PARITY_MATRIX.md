# Apple native feature parity matrix

Status: Partial. The app builds for iPhone, iPad and Mac, and CI runs its Swift, Rust and UI tests on every push. Most areas below have native code, but few are verified beyond those tests, and some do not work yet. Each row says Done, Partial or Not working, with the evidence.

Source inspected: local Windows working tree at commit `185ee9a1019c8b7bc685d22dabf1b699579189cc` plus its pre-existing uncommitted changes. All changes and untracked modules have been integrated into the native Apple platform workspace in `Apple/**`.

The authentication, collaboration and permissions traces and verification are detailed in [AUTH_COLLAB_AUDIT.md](AUTH_COLLAB_AUDIT.md).

The focused navigation, reader, project, file and media traces are in [READER_RESOURCE_PARITY.md](READER_RESOURCE_PARITY.md).

The storage, account, permissions and collaboration requirements are detailed in [STORAGE_SYNC_REQUIREMENTS.md](STORAGE_SYNC_REQUIREMENTS.md).

Done means the behaviour exists and is covered by tests in CI. Partial means code exists but parts are missing or only checked by unit tests. Not working means the feature does not do what the row describes yet.

## What is verified

- CI (`.github/workflows/apple-platforms.yml`) builds the shared Rust store, runs the Swift core tests and the UI tests on iPhone, iPad and Mac, and packages unsigned IPA, app, ZIP and DMG files.
- The Rust crates used by the app have their own unit tests (store, collaboration, MCP and MCP authorization).
- Nothing here has been tested on a physical iPhone, iPad or Mac by a person, and the builds are unsigned.

## Known gaps

- AI: chat only. Real providers stream replies, but the assistant has no workspace tools yet, see the AI row.
- Drawing: the renderer now draws masks, the supported effects, the eraser, alpha lock, nested layer groups and every desktop shape and brush kind, verified by unit tests in CI but not on a device. Still missing: shape correction, image, reference and raster elements, mask images, textured brush tips, the temperature, sharpen and pixelate adjustments, full text layout and pixel parity with the desktop tile rasterizer.
- Haptics: only the `WorldsHaptics` helper in `WorldsApp.swift` exists; Core Haptics patterns are not used.
- Accounts, collaboration and Discord have code and unit tests but are not verified against the live services.
